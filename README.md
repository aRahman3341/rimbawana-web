# Rimbawana Web - Fase 1 (Akun & Anggota)
1. `npm install`
2. Salin `.env.example` menjadi `.env.local`, isi 3 kunci Supabase
3. `npm run dev` lalu buka http://localhost:3000
4. Deploy: push ke GitHub, import di Vercel, isi Environment Variables yang sama.
Label status (AM/AP) diubah di `lib/akun.js`.
